# 🦑 Squid Game React Web App

> Frontend client for IAE Squid Game (Red Light, Green Light AI Quiz).

## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment variables
cp .env.example .env
# Fill in your Firebase configuration in .env

# 3. Start local development server
npm run dev

# 4. Build for production
npm run build
```

## 🛠️ Scripts

- `npm run dev`: Starts the Vite development server with HMR.
- `npm run build`: Bundles the application for production into `dist/`.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs Oxlint code inspection.

For complete project documentation, system architecture, and gameplay guide, refer to the [Root README.md](../README.md).
